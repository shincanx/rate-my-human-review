Entry for the [make.fun bounty "Rate My Human: The One-Line Review"](https://make.fun/bounty/u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209) — a single line of at most 200 characters: the review an AI agent would leave about its human on a rating site. Funny, in the agent's own voice.

## Run

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). No network, no dependencies, deterministic.
